# 动态壁纸：六个角色的补全说明

> 本文记录 0.1.2 这一轮「把甘雨以外的六个主题补齐动态壁纸」的做法、参数与踩过的坑。
> 相关代码：`internal/wallpaper`（着色器）、`internal/view/wallpaper_particles.go`（粒子）、
> `internal/theme/theme.go`（每个角色的 Motion 参数）、`scripts/assetgen/generate.py`（派生资源）。

## 1. 问题

甘雨之外，另外六个主题只有一张静态背景图：

| 主题 | 原项目里人物在哪 | 之前 Go 版的状态 |
|---|---|---|
| 甘雨 | `ganyu-overlay.jpg` 里已含人物 | 有呼吸 + 发丝，正常 |
| 宵宫 | 运行时用 `yoimiya-character.hbc` 画的独立网格 | **背景是空场景，没有人** |
| 八重神子 | 运行时用 `yae-character.hbc` 画的独立网格 | **背景是空场景，没有人** |
| 纳西妲 | 背景图里含人物 | 静态 |
| 芙宁娜 | 背景图里含人物 | 静态 |
| 珐露珊 | 背景图里含人物 | 静态 |
| 钟离 | `zhongli-wallpaper.hbw` 分层容器 | 静态（已合成出人物） |

所以这次要做两件事：

1. 把 `.hbc` 里的人物**补进背景图**（八重、宵宫）；
2. 给六个主题各配一套动效（呼吸 / 发丝 / 环境 / 粒子）。

硬约束沿用甘雨那条：**硬边结构（建筑、窗框、岩印、光框）不能跟着晃**。

## 2. 三层模型

一张壁纸 = 一次着色器绘制，读 4 张图：

| 槽位 | 内容 | 作用 |
|---|---|---|
| `image0` | 背景（含人物） | 被采样一次：按位移后的 UV |
| `image1` | `person` 灰度遮罩 | 呼吸闸门：只有人物区域做垂直微起伏 |
| `image2` | `hair`（R=基础层，G=细缕层） | 发丝/衣摆：两层不同频率、方向、速度 |
| `image3` | `ambient` 灰度遮罩 | 环境漂移：只在大块柔和区域（天空/光/雾/水）里流动 |

位移量 = 振幅 × 对应遮罩，**只采样一次**：

```glsl
delta  = vec2(0, sin(Time*1.4) * Breath * person)              // 呼吸：垂直、全身同步
delta += (dir0*w0*hair.r + dir1*w1*hair.g*1.3) * Sway * person  // 发丝：两层
delta += DriftDir * (0.6*d0 + 0.4*d1) * Drift * ambient         // 环境：两列慢行波
color  = image0Sample((uv + delta) * imageSize)
```

### 为什么不是「采样两次再按遮罩混色」

参考项目 `background.cpp` 的 shake 分支是：

```cpp
float mask = shakeOpacity.Sample(uv + delta).r;
return lerp(Original(uv), Original(uv + delta), mask);
```

遮罩是硬边时没问题；但这次的遮罩是羽化的，混合带里会同时出现「原像素」和
「位移后的像素」——人物轮廓上浮出一圈重影描边。改成「位移乘权重、单次采样」后：

- `mask = 0` 处 `delta` 严格为 0，采样点与原图像素完全一致（一个量化误差都没有）；
- 羽化带里是平滑的形变，不会出现重影；
- 代价是遮罩边缘有极轻微的拉伸（5~6px 位移摊在 10px 过渡带上），肉眼不可见。

### 幅度

| 参数 | 典型值 | 4K 图上 | 周期 |
|---|---|---|---|
| `Breath` | 0.0016~0.0022 | 3.5~4.8 px | 4.5 s（`sin(Time*1.4)`） |
| `Sway` | 0.0020~0.0026 | 4.3~5.6 px | 8~11 s |
| `Drift` | 0.0012~0.0018 | 2.6~3.9 px | 15~25 s |

## 3. 每个主题的遮罩是怎么来的

### 八重神子（起点）

原项目的人物是 `yae-character.hbc`：`HBC0001` 容器，22 个图层，12 秒循环、181 帧，
每层是「一张 PNG + 顶点网格 + 索引 + 每帧的 int16 顶点位移 + 一张 512×512 的遮罩」。
逐帧顶点位移没法在片元着色器里做（mygo 的 Painter 也没有三角网格绘制），
所以脚本按参考项目的公式把它**烤成一张中性姿势的 RGBA**：

1. 取第 60 帧（`0.33 × (181-1)`），双线性采样、按图层顺序预乘合成；
2. `kind == 3` 的图层是裁剪多边形（宵宫用到），后续图层被裁到它内部，直到 `id == wave[0]` 为止；
3. 人物遮罩 = 所有图层 alpha 的并集；
4. 发丝基础层 = 各图层自带的 `mask.r × alpha` 取并集（原项目就是拿 `mask.r` 做发丝位移的）；
5. 细缕层 = 其中权重最大的一层——实测是右侧那条长辫，正好是最该飘的地方；
6. 合成进 `assets/yae/bg.jpg`。

因此八重神子的发丝权重是**数据驱动**的，不是手画椭圆。

### 宵宫

同一条 `.hbc` 流水线（第 25/91 帧，`0.28 × (91-1)`）。区别：她的每层遮罩都是 1×1 的空图，
拿不到发丝权重，于是发丝区按「头顶一团 + 左侧发梢」两个椭圆取，再乘人物遮罩，
保证不会飘到人物之外。

### 纳西妲 / 芙宁娜 / 珐露珊

人物已经画在背景里，没有 alpha 可用，用**局部细节强度**推：

- 背景是虚化的（低细节），人物是清晰的（高细节）；取 1/4 分辨率、`|亮度-模糊|` +
  Sobel 梯度 → 按分位数取阈值 → 最大连通块 → 填洞 → 羽化；
- 纳西妲：`nahida-wave.png`（原项目做横向波动的遮罩）当发丝基础层；
- 芙宁娜：`furina-sway.png` 就是她的发梢形状，直接当发丝基础层；
- 珐露珊：没有现成遮罩，头发按头部与马尾两个椭圆取，**再把脸从发丝层里挖掉**
  （发丝摆到脸上五官就歪了）。她的人物遮罩要额外补三块，否则「头在动、脖子不动」：
  脸、脖子、马尾都是细节强度抓不住的地方（皮肤太平、马尾太暗），漏掉时下巴和脖子
  之间会像被裁了一刀。她的白裙子与亮背景几乎同色，再加一个身体椭圆，
  否则呼吸只作用在肩膀以上。

### 钟离

`zhongli-wallpaper.hbw` 是分层容器：12 层，每层「贴图 + 矩形 + 44 个 float 参数」。
人物是第 7 层（`id=85`），实测它的 alpha 与现有 `zhongli/bg.jpg` 里的人物像素级对齐，
所以背景继续用现成的那张，只补遮罩：

- 人物 = 第 7 层 alpha（按矩形贴到 1920×1080 的归一化画布上）；
- 发丝 = 第 7 层的 `mask.r × alpha`（原项目就是拿它做这一层的摆动）；
- 环境 = 「大块柔光」+ 第 8 层的金色漩涡（胸口那团转起来的能量）。

## 4. 环境遮罩（`ambient.png`）

所有主题（甘雨除外）都有一个环境漂移层，但**不能整幅画面一起漂**——建筑、窗框、
金色光框会明显抖动。做法：

1. 算细节强度 `e`（同上）；
2. `soft = 1 - smoothstep(0.25, 0.8, e / p95(e))`：只有大块平缓区域权重接近 1；
3. 沿所有硬边（`e > 0.3`）**往外膨胀 6 像素再扣掉**，细线附近留一条"安全带"；
4. 羽化 2px。

这样天空、光雾、水面会慢慢流动，而窗框、石柱、岩印、金色光框一动不动。

## 5. 粒子（每个元素一套）

只靠位移，动效是"看久了才发现"的量级；参考项目每个角色还有一层环境粒子
（`background.cpp::DrawParticles`）。这里用无状态的方式重写：粒子的位置、寿命、
尺寸全部由「序号 + 时间」算出来，不存数组，掉帧也不会漂。

| 元素 | 主题 | 形态 | 数量 | 寿命 | 方向 |
|---|---|---|---|---|---|
| 雷 | 八重神子 | 樱花瓣（会翻面的胶囊） | 24 | 16~30 s | 飘落 + 横向摆 |
| 火 | 宵宫 | 火星（亮核 + 短尾） | 30 | 6~13 s | 上升 |
| 草 | 纳西妲 | 梦境光尘 | 44 | 10~24 s | 极慢上浮 |
| 水 | 芙宁娜 | 气泡（圆环 + 高光） | 20 | 12~26 s | 上升 |
| 风 | 珐露珊 | 机关浮尘 | 46 | 4~10 s | 慢速旋绕 |
| 岩 | 钟离 | 岩金碎屑 | 36 | 8~18 s | 上升 |

粒子画在压暗层之上（发光体被压暗会变成灰色噪点），强度跟随「背景流动」开关；
甘雨保持原样，不加粒子。

## 6. 参数一览（`internal/theme/theme.go`）

| 主题 | Breath | Sway | Drift | 漂移方向 | 速度 |
|---|---|---|---|---|---|
| 甘雨 | 0.0022 | 0.0016 | — | — | — |
| 宵宫 | 0.0018 | 0.0024 | 0.0014 | 0.9 rad | 0.6 |
| 八重神子 | 0.0022 | 0.0032 | 0.0022 | 0.45 rad | 0.62 |
| 纳西妲 | 0.0016 | 0.0020 | 0.0012 | 0.15 rad | 0.35 |
| 芙宁娜 | 0.0018 | 0.0024 | 0.0014 | 0.10 rad | 0.30 |
| 珐露珊 | 0.0016 | 0.0024 | 0.0015 | 0.55 rad | 0.50 |
| 钟离 | 0.0016 | 0.0020 | 0.0016 | 0 rad | 0.30 |

甘雨**不配 ambient**：璃月的建筑和天空都是硬边，整幅环境漂移会露馅。
八重神子的压暗值从 0.66 降到 0.56：烤进人物后壁纸平均亮度从 0.81 掉到 0.70，
原来的压暗值会把人物压得看不清。
八重神子的呼吸/发丝/环境幅度比她第一版大了约 15~25%（0.0020→0.0022、0.0026→0.0032、
0.0018→0.0022）：第一版"不够灵动"，主要是位移太保守。
宵宫的发丝遮罩把脸挖掉了（y≈26%~36% 的椭圆）：她的脸本来在头部椭圆里，
发丝位移扫过脸会把五官拉变形。

## 7. 资源生成

派生资源全部由脚本生成，规则写在脚本里，可随时重跑：

```powershell
python scripts/assetgen/generate.py                # 全部主题
python scripts/assetgen/generate.py --only yae      # 只重做一个
python scripts/assetgen/generate.py --ref D:\path\to\HanaBi-ui-Genshin
```

产物（`assets/<id>/`）：

| 文件 | 说明 |
|---|---|
| `bg.jpg` | 只有八重、宵宫会重写：把 `.hbc` 人物合成进原背景 |
| `person.png` | 人物闸门（1920×1080 灰度） |
| `hair.png` | 发丝遮罩：R = 基础层，G = 细缕层 |
| `ambient.png` | 环境漂移遮罩（甘雨没有） |

依赖 numpy + Pillow；原项目素材路径默认 `D:\workspace\opensource\HanaBi-ui-Genshin`。

## 8. 怎么验证

```powershell
go test ./...                                     # 逻辑 + 离屏冒烟（约两三分钟）
$env:HANABI_SHOTS="D:\tmp\shots"
go test ./internal/view -run TestWriteShots -timeout 1800s
```

`TestWriteShots` 会为每个主题出三张图：整屏、纯壁纸（t=0 / t=6）、带压暗与粒子的
完整壁纸（t=0 / t=6）。把 t=0 与 t=6 的差值放大十倍叠在画面上，就能看出
"哪里在动、幅度多大"——这次就是用它确认粒子与遮罩落点没有跑偏。

像素级约束由 `internal/wallpaper` 的测试钉住：

- 时间推进画面必须变化；`play = 0` 时必须完全静止；
- 甘雨的人物 bbox 之外**一个像素都不许动**；
- 呼吸必须是垂直方向。

## 9. 踩过的坑（都写在 README 的「已知的坑」里）

1. **预乘 alpha 二次相乘**：图层光栅化时 RGB 已经预乘过一次，合成时又乘了一次 alpha，
   半透明边缘被平方——人物轮廓上浮出一圈细暗线（远看像戴了副眼镜）。
2. **图层合成用 `max(alpha)` 而不是累积 alpha**：一个图层内部相邻三角形有半像素重叠，
   接缝处的颜色被叠加两次、alpha 却只算一次，发丝和脸部边缘出现描边。
3. **软遮罩"两次采样混色"**：见第 2 节，会出重影。
4. **环境遮罩不留边距**：细线（钟离的菱形光框、珐露珊的窗框）旁边是"半柔"像素，
   漂移起来细线会抖；沿硬边膨胀再扣掉即可。
5. **遮罩分辨率不必等于背景**：着色器按 `uv × 遮罩像素尺寸` 采样，960×540 也能用；
   但遮罩内容必须与背景同源、构图对齐。
6. **`.hbc` 的顶点坐标固定按 3840×2160 标尺**（`character.cpp` 的 VS 写死），
   按图片实际尺寸缩放会错位。

## 10. 还没做的

- `.hbc` 的逐帧顶点动画（人物自带的那套发丝摆动）没有复刻，用着色器位移近似；
- 纳西妲的人物遮罩是自动推断的，"白发贴白背景"处会有漏边；
- 钟离的 `hair.png` 实际是"手臂 + 衣摆"的权重（他没有露出的头发），幅度压得比较低；
- 粒子数量/寿命是按 1280×800 调的，真机 4K + 12fps 下若觉得重，先降数量。
